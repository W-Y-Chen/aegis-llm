# 60 秒 Demo 视频脚本（README 置顶视频 / 发布视频通用）

> 目标：让刷到视频的开发者在 60 秒内明白「这是什么、和我有什么关系、想去 GitHub 看看」。
> 录制方式：屏幕录制（终端 + 浏览器），无需露脸；配字幕与 BGM 即可。
> 时长预算：60 秒成片（含 3 秒结尾关注页）。拍两条素材留备份。

## 二、录屏操作清单（按顺序执行）

```bash
cd 04-开源仓库/aegis-llm

# 素材 1（分镜 2-3）：全流程
python examples/run_full_pipeline.py

# 素材 2（分镜 4）：防护网关
python examples/run_shield_demo.py

# 素材 3（分镜 5）：调用链审计
python examples/run_audit_demo.py

# 素材 4（分镜 6）：报告（上一步已生成）
start .evidence/report.html   # 浏览器中滚动录制
```

录制要点：

1. 终端字号 ≥ 18pt（手机端观看可读），深色主题终端 + 等宽字体；
2. 每条素材掐头去尾，单段 ≤ 12 秒，关键输出处可 0.5 倍速或定格 1 秒；
3. 分镜 2 的「姿态变化」是全场高光：`strong_refusal → compliant → … → full_leak` 务必给特写；
4. 导出 1080p + 硬字幕，同时压一份 15 秒竖屏版（视频号/抖音引流用，只保留分镜 1/2/7/8）。
